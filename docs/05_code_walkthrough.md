# 向组员和老师解释代码

现在新增代码做的是运行模型之前的准备检查。数据检查通过不等于神经网络训练成功。

| 文件/函数 | 输入 | 做什么 | 输出 |
| --- | --- | --- | --- |
| `check_data.py / load_paths` | 每个人的 JSON 路径配置 | 找到原图和组成图根目录 | 两个可用的路径对象 |
| `check_data.py / image_paths` | 一个划分目录 | 收集 PNG 完整相对路径 | 不重复的文件路径集合 |
| `check_data.py / check_category` | 两个根目录和一个类别 | 比较缺图、多图、空目录 | 各划分的数量和通过状态 |
| `check_data.py / main` | 终端参数 | 串起配置读取与检查，可保存报告 | 终端报告；成功退出码 0，失败为 1 |
| `verify_sources.py` | 导入时的文件指纹清单 | 对比当前文件 SHA-256 | 哪些文件仍相同或被改动 |
| `check_environment.py` | 当前 Python 环境 | 查看软件版本；选用 --gpu 时检查 CUDA | 环境清单，不加载模型权重 |

演示可先运行 `verify_sources.py`，再运行 `check_data.py`。解释：“我把电脑路径从代码中移到个人配置，因此组员换电脑不用修改程序；配对使用完整路径，避免把不同文件夹的同名图片认错。”

作者代码的后续讲解顺序：`argparser.py` 设置 → `salad_dataset.py` 读图与合成 → `train_salad.py` 前向预测、损失与参数更新 → `test_salad.py` 推理与评分。改进代码实现后再补具体函数和消融效果，不能把尚未实现的功能讲成已经完成。
