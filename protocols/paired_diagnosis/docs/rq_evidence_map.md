# 研究问题与证据对应表（A 维护）

机器可读版：`../data/rq_evidence_map.csv`。本表是全组的"结论纪律"：**每个结论只从对应的
证据来，证据做到哪一步，结论就只能写到哪一步。**

## 三个研究问题

### RQ1 改进是否对真实缺陷有用？

| 项 | 内容 |
|---|---|
| 必须的证据 | Screw Bag、Pushpins 各一对**同起点、同步数**的原版 / 改进 SALAD，在官方测试集分别报告**逻辑与结构 AUROC**（条件允许时补第三类 Breakfast Box 两组） |
| 对应实验 | ABL-SB-REF / CONS / RANK / COMB；XCAT-PP-REF / COMB；（XCAT-BB-*） |
| 能得出的结论 | 改进是否改善真实逻辑异常检测，以及有没有牺牲结构异常检测 |
| 措辞边界 | 只覆盖实际做了改进的类别——两类做了改进就不能宣称"对全部五类普遍有效"；作者权重成绩只列参照，不替代同预算对照 |

### RQ2 模型区分的是规则，还是"图被改过"？

| 项 | 内容 |
|---|---|
| 必须的证据 | 用**未参与训练的 FD 源图**生成配对诊断：违规版本分数高于合法版本的比例（M1）、样本数、合法移动造成的分数变化（M3）；计数基线作参照 |
| 对应实验 | DIAG-SB-{run}、DIAG-PP-{run}、DIAG-PP-COUNT |
| 能得出的结论 | 模型能否在**两张都被编辑过**的图之间做出正确区分（总数、亮度、编辑流程都尽量对齐，只有规则合法性不同） |
| 措辞边界 | "更经常给违规图更高分"≠"理解规则"；组成图配对诊断≠RGB 系统鲁棒；平分情况单列；源图数与编辑对数分开报 |

### RQ3 效果来自好样本，还是排序损失？

| 项 | 内容 |
|---|---|
| 必须的证据 | Screw Bag 上**固定同一批核查样本**、原有监督与训练预算，只开关排序损失；R0 vs R1 分离"更换样本方案"的效应 |
| 对应实验 | RCT-SB-R0 / R1 / R2（R1/R2 共享 D 固定的 70 条样本，sha256 核对） |
| 能得出的结论 | 排序损失是否带来超出样本方案的额外收益 |
| 措辞边界 | 不把样本筛选的收益算给损失；SALAD 原版已含组件级合成——更可信的贡献表述是"按产品规则构造受控配对样本，并通过真实基准、配对诊断与同样本消融检验模型是否更有选择地响应规则错误" |

## 证据三级结构（报告叙事顺序）

1. **真实异常检测**（RQ1）：五类基准表 → 同预算改进表——说明改进在真实测试集上的作用与代价；
2. **配对诊断**（RQ2）：总数不变的格内 vs 跨格、重摆 vs 缺件、规格替换——说明作用出在"规则"上；
3. **排序控制**（RQ3）：同批样本开关排序——说明作用出在损失上而不是样本上。

三层证据合起来才是完整叙事：*改进有效（RQ1）→ 有效在规则而非编辑痕迹（RQ2）→
效果可归因于设计而非样本运气（RQ3）*。任何一层缺失，结论降级表述。

## 答辩预演（A 出题，全组备答）

1. **"模型变好，是因为见到了更好的样本，还是你们的排序损失？"** → R1 vs R2（同批样本只差开关）；
   R0 vs R1 说明样本方案本身的效果——三层归因讲清楚。
2. **"模型是理解了规则，还是只是识别出图被编辑过？"** → 配对诊断（两侧都被编辑）+ 计数基线
   （A 对两侧总数相同，数总数的基线无法区分）。
3. **"为什么只做两类（或三类）改进？"** → 十四天预算与优先级：关键对照和重复优先于类别数量；
   结论范围如实。
4. **"组成图上的改进能迁移到真实 RGB 吗？"** → 当前为组成分支诊断；RGB 光度路径依赖组件预测器，
   未验证就明说。
5. **"PatchCore 逻辑 54.8 是不是说明它很弱？"** → 不是；它是经典局部特征基线，
   语境特征并非完全不能检测逻辑异常——引用须谨慎（进度报告 §5.2 原表述）。
