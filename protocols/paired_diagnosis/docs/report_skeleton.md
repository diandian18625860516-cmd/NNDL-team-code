## 写作红线（A 终稿前逐条过）

1. **没跑通的不写成完成**：光照一致性（若组件预测器未到位）、第三类（若未启动）只出现在
   "计划/局限"，方法节不得写成已实现；
2. 结论范围 = 实验覆盖范围（两类或三类），不写五类普遍有效；
3. "更经常给违规版本更高分"，不写"理解规则"；
4. 作者权重成绩与自训成绩分列并标注阶段（author_weights / from_scratch / continued_training /
   memory_bank_fit），不冒充从头训练；
5. 数据数字来自 C 冻结表；每表注明类别/口径/样本数/种子与重复次数；
6. 统计单位：源图数与编辑对数分开报；
7. B 的真实数据示例图与 D 的合成诊断图分开caption，不混排；
8. 报告 9–12 页；相似度 <20%；**AI 生成内容检测 <30%**——各人须在自己素材基础上改写；
   AI 协助按课程要求如实披露（贡献节注明"使用 AI 编程助手协助实现 XX 与验证"）。
