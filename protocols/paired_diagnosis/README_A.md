## 2. 三层证据 → 两个研究问题（一页速览）

- **RQ1 改进对真实缺陷有用吗** → 同起点同步数原版 vs 改进（SB 四组 + PP 两组）；
- **RQ2 区分的是规则还是"图被改过"** → 配对诊断（两侧都被编辑、总数不变：
  PP 格内 vs 跨格、SB 重摆 vs 缺件/规格替换）+ 计数基线；
- **RQ3 好样本还是排序损失** → R0/R1/R2 同批 70 条样本只差排序开关。
任何一层缺失，结论按 `rq_evidence_map` 的措辞红线降级表述。
